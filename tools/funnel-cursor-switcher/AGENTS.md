# ファンネル・カーソル切替の作業範囲

作業前に [開発対象.md](開発対象.md) を確認してください。最新の配布対象はフィンファンネル・キュベレイ・サザビー・Hi-νガンダム・Hi-νガンダムHWS・ストライクフリーダムのドラグーンの6種類です。

凍結中13種は、素材・演出コード・装備別設定を削除せず保管します。通常の選択一覧と既定プレビューには出しません。ユーザーが明示的に再開するまで、凍結装備の形状・配色・演出の追加改修は行わないでください。

対象の定義は `equipment_catalog.py` と開発対象の記録をそろえて更新します。ユーザーの最新の明示指示がこの記録より優先します。

## 待機モーションの回転軸

ユーザーは「ビームが出ますよね。そのビームの棒が回転軸ですよ」と指定し、「ビームを出せ、というわけではなく、軸の指定をしています」と明確にしました。回転軸はビームの射線に相当する装備の長手方向です。画面の左右方向のX軸と解釈した初期記録は誤りなので復活させないでください。通常カーソルの左上への長手方向を保ったまま、その射線に沿う軸でコの字全体をロールさせます。ビームや軸の線を表示する依頼ではありません。

「これ以降作るやつも同じ軸で回転する」という指定を引き継ぎ、今後も射線方向の軸で統一します。対象はマウスポインター本体です。一種類ずつ作成し、まずフィンファンネルだけを扱います。凍結装備への追加は行いません。

開始姿勢は既存の通常カーソルの左上向きです。横向きの別のコの字へ置き換えたり、先に画面内で向きを回したりしません。参考写真は薄い白い外板・濃紺の内面・短いヒンジの構造を確認するために使い、写真の向きに開始姿勢を変えません。
