# ファンネル・カーソル切替の作業範囲

作業前に [開発対象.md](開発対象.md) を確認してください。最新のユーザー指定は6系統・12種に限定しています。

凍結中13種は、素材・演出コード・装備別設定を削除せず保管します。通常の選択一覧と既定プレビューには出しません。ユーザーが明示的に再開するまで、凍結装備の形状・配色・演出の追加改修は行わないでください。

対象の定義は `equipment_catalog.py` と開発対象の記録をそろえて更新します。ユーザーの最新の明示指示がこの記録より優先します。

## 待機モーションの回転軸

ユーザーは2026-11-23に、フィンファンネルの待機横回転を「横軸を中心に、上の板と下の板が入れ替わる回転」と指定し、「これ以降作るやつも同じ軸で回転する」と指示しました。以降の機体も画面の左右方向の横軸（X軸）で統一します。縦軸まわりに正面・側面・裏面を左右へ切り替える回転や、画面上での平面的な回転へ置き換えないでください。

ポインター本体が対象です。機体は一種類ずつ作成し、フィンファンネルはコの字の状態を保ったまま上側・下側が入れ替わるように回します。凍結機体への追加は従来どおり行いません。
