# RX-93 νガンダム用フィン・ファンネル

展開時の1基をBlenderで造形した。2枚の等長の板は平行で、短い接続部の両端に折り曲げ部がある。各板は白い外板と濃紺の内側のフレームから成る。白い外板は根元寄りで三角形に盛り上がり、先端へ向かって細くなる。途中にスリットが1本あり、先端のくぼみに赤、根元のくぼみに緑の小面を入れた。内側のフレームには溝と角穴の縁を、接続部の内側には14穴の金属板を造形した。開始時の開口は撮影画面の左上を向く。

部品の構成と折り曲げ位置には[バンダイのフィン・ファンネル組立説明書](https://manual.bandai-hobby.net/pdf/4159.pdf)を参照した。白い外板、濃紺の内面、黄の角部の見え方はユーザー提供の模型写真に合わせた。板幅・厚み・間隔・内面の細部は写真から推定した比率で造形している。

Blender 4.3で以下を実行すると、モデル、撮影用シーン、36枚の透過PNGを生成する。出力先には絶対パスを指定する。

```sh
blender -b --python-exit-code 1 -P create_model.py -- /tmp/fin-model
```

モデルの親オブジェクトのローカルY軸は、2枚の板の間を長手方向に通る。Blenderシーンの1〜36フレームを再生すると、固定カメラの前でモデルが10度ずつ回転する。GLBにはモデルのメッシュと材質を収録した。

アプリ用の撮影は同じシーンから行う。次の例ではモデル生成後に48方向の待機回転、飛行4コマ、ヒンジ展開4コマ、伸ばした収納姿・中央の折り返し姿を撮影する。パッケージ化の前にアプリのディレクトリから実行する。

```sh
blender -b /tmp/fin-model/fin-funnel.blend --python-exit-code 1 -P models/fin-funnel/render_assets.py -- /tmp/fin-baked
python build_fin_idle_art.py /tmp/fin-baked
```
