# ファンネル・カーソル切替

Windows 10・11 向けの通常ポインター切替ツールです。ファンネルやビットなどを25種類収録しています。Windowsの標準表示（100%）では、縦横比を保った絵を最大32×32ピクセルで表示します。拡大表示向けの画像も収録しています。装備の配色は原作や立体資料を参考にし、色が分からない装備には機体の配色を使っています。

## 使い方

1. [Releases](https://github.com/alz7485/codex2/releases) の「ファンネル・カーソル切替」から `FunnelCursorSwitcher-windows-x64.zip` をダウンロードし、ZIP全体を展開します。
2. `FunnelCursorSwitcher.exe` を起動します。
3. たとえば「ファンネル」→「フィンファンネル」を選び、「適用」を押します。

変更前に戻すには、「元に戻す」→「変更前のカーソル」を選んで「適用」を押します。最初に変更するときに、現在の通常ポインター設定を保存します。待機中や文字入力用などのポインターはWindows側で管理します。

## 演出の選び方

最初は「標準」で試してください。機体ごとのノズルから、移動速度に応じた噴射光と短い軌跡が出ます。「戦闘モード」は通常演出8種類すべて、「控えめ」は淡い噴射と短い軌跡のサンプルです。

| 演出 | 試せること |
| --- | --- |
| ブースト噴射 | 機体別ノズル、色、速度反応、噴射長と太さ |
| 移動残像・軌跡 | 曲線、直線、機体の残像、粒子、インコム風ワイヤー |
| クリック | 左・右・ダブルで別の色と形。ダブル成立時は最初の左クリックの光を専用演出に切り替えます |
| 待機光・浮遊 | 停止後に後端が明滅。浮遊幅を変えてもクリック位置は一定です |
| 粒子 | 移動・停止・クリックから選んで発生。火花、煙、破片などを調整できます |
| 随伴ファンネル | 1～3基。移動時は隊列で追従し、停止時は旋回、クリックで前に展開します |
| 展開・収束 | 選んだきっかけで光輪を展開。随伴機を有効にすると隊列の距離にも反映します |
| レア演出 | 停止中の回転、隊列変化、閃光。候補・平均頻度・最短間隔を選べます |

各行のチェックで個別に切り替え、スライダーで主な値を調整します。「詳細」で色やタイミングを変えられます。「全ON」「全OFF」「初期値に戻す」もまずプレビューに反映されます。

プレビューの「自動」は移動、停止、左・右・ダブルクリックを順に再生します。枠内で実際に操作することもできます。別のカーソルを見ても、開いている間は編集中の値を保持します。

- **適用**で、選択中のカーソルと演出をデスクトップに反映し、そのカーソルの設定を保存します。Windowsポインターを復元するときは「元に戻す」→「変更前のカーソル」→「適用」です。
- **管理**で、編集中の見た目に名前を付けて保存できます。名前付きプリセットの上書き・複製・改名・削除、JSONの読み込み・書き出しもここから行います。
- 設定は共通値、分類、プリセット、カーソル個別値の順に重ねます。「詳細」の右欄が各値の設定元です。プリセットを変えても個別値を優先します。「初期値に戻す」で選択中のカーソルを分類の標準に戻せます。

最小化してもデスクトップの演出は続きます。アプリを閉じると演出が消え、適用した通常ポインターはWindowsに残ります。次に起動すると、前回のカーソルが選ばれます。「適用」で演出を再開できます。

## 装備ごとの特殊演出

「ファンネル」から対応する装備を選ぶと、「特殊演出」欄が表示されます。チェックして「適用」を押し、デスクトップで **Ctrl＋Shiftを押したまま左クリック** すると発動します。通常クリックや待機中の自動発動はありません。同じ演出の再発動には3秒の間隔があります。

| 装備 | 特殊演出 |
| --- | --- |
| キュベレイ、キュベレイMk-II（プル機・プルツー機） | 「螺旋ビット放出」で小型ビットがクリック位置から順に渦を描いて広がります。初期値は6基で、2～10基、広がり、回転数、飛行時間、光跡の色を調整できます。 |
| フィンファンネル、νガンダムHWS、Hi-νガンダム | 「Δ型Iフィールド」で3基が三角形の頂点に展開します。半透明のフィールドがポインターを囲んで消えます。半径、持続時間、色を調整できます。 |

**発動操作の変更**は、特殊演出の「詳細」→「発動キー」「発動ボタン」→「閉じる」→「適用」です。Ctrl・Shift・Altの1～3キーと、左・中・右クリックを組み合わせ、装備ごとに保存できます。クリックは操作中のアプリにも通常どおり届きます。

プレビューの「特殊演出を試す」で、デスクトップに適用する前に確認できます。初めて選ぶ対応装備は特殊演出が有効です。旧版で保存済みの装備には、使いたい演出のチェックを入れてください。[2つの特殊演出の見本（GIF）](https://github.com/alz7485/codex2/blob/main/tools/funnel-cursor-switcher/special-preview.gif)

## 設定ファイルと復旧

保存場所は `%LOCALAPPDATA%\FunnelCursorSwitcher` です。USBメモリーや読み取り専用フォルダから起動しても設定はユーザー単位で保存されます。

| ファイル | 内容 |
| --- | --- |
| `effects.json` | UTF-8、`schema_version: 1`。前回の `active_cursor`、ユーザーの `presets`、分類名と拡張子付きファイル名をキーにした `cursors` を保存。各カーソルは `preset` と差分 `overrides` を持ちます |
| プリセット交換用JSON | `schema_version`、`name`、`effects` を格納。`effects` は演出ID→項目→値。色は「機体色」または `#RRGGBB` |
| `arrow-original.json` | Windowsで選んでいた通常ポインターの復元用バックアップ |
| `cursor-*.cur`、`cursor-*.ani` | Windowsが参照する適用済みカーソルのコピー |

設定が壊れている場合は初期値で開き、次の保存時に元データを `effects.bak` へ退避します。演出だけ初期化するにはアプリを終了し、`effects.json` を別名へ移して起動します。復元用バックアップと適用済みカーソルはそのまま保管してください。復元用バックアップを紛失した場合は、Windowsの「マウスのプロパティ」→「ポインター」で「通常の選択」を設定できます。

UAC画面、排他フルスクリーン、リモートデスクトップではWindows側で重ね描画が制限される場合があります。画面の座標を取得できない間は演出を隠し、描画エラー時は演出を停止して画面に理由を表示します。「適用」で再開できます。画面全体を使うゲームでは「全OFF」→「適用」も利用できます。

## カーソルの追加

EXEと同じ場所の `カーソル` フォルダに分類フォルダを作り、中に `.cur` または `.ani` を入れてアプリを再起動します。同名の `.png` があればプレビューに表示します。

```text
FunnelCursorSwitcher/
├── FunnelCursorSwitcher.exe
├── _internal/
└── カーソル/
    ├── ファンネル/
    │   ├── フィンファンネル.cur
    │   └── フィンファンネル.png
    └── 自作/
        └── 好きなカーソル.cur
```

`_internal` と `カーソル` を含むフォルダごと使います。

## Windowsでビルド

64ビット版 Python 3.12 をPATHに追加した環境で、このフォルダから次を実行します。

```powershell
.\build-onedir.cmd
```

出力先は `dist\FunnelCursorSwitcher-windows-x64.zip` です。バッチは仮想環境を作り、PyInstallerで次のコマンドを実行してから、カーソルフォルダをコピーしてZIPにします。

```powershell
.\.venv-build\Scripts\python.exe -m PyInstaller --onedir --windowed --clean --noconfirm --name FunnelCursorSwitcher FunnelCursorSwitcher.pyw
```

Pythonから直接使う場合は、Pillowをインストールしてから起動します。

```powershell
py -3.12 -m pip install Pillow==12.3.0
py -3.12 .\FunnelCursorSwitcher.pyw
```
