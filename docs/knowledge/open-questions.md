## 2. E3D 4.0で要確認の規則

- 旧PDMS資料の書名・版・発行年、およびE3D 4.0への適用範囲。
- OBST対象が「最初の20個まで」の制限。新しい製品でも有効と断定しない。
- 表示既定値、TUBE/CLの相互排他、OBSTとLEVELの優先、UPDATE・Draw List更新の挙動。
- TVISIBLE / BVISIBLEがPARAGONでは無効という説明の、E3D各モジュールでの有効範囲。
- Design Parameter Arrayの10項目という上限。
- TEMP=-100000の意味、単位、特殊値としての扱い。
- SCYL負高さの正確な始点・終点・方向と、他プリミティブで許される負寸法。
- 保温なしの0寸法を許す形状・属性と、一般の不正な0寸法との区別。
- セッションMODEL SETTINGSの単位変換・次元非保持が現行製品でも同じか。

## 3. 構文や階層の不足

- PAXI / PLAXI / PTCDIR の正式文法。符号、複数角度、式、DDANGLE、TWICE、軸の別名、点参照を含む形式。
- PTCDIRの多軸指定の回転順・意味。単純な文字列置換や未知値の0扱いで済ませない。
- PTPOS / PTCPOSの全仕様。この写真列の3型の説明を理由に既存のPTPOSを削除しない。
- 各要素名の有効な長表記・最小略記。4文字への一括切り詰めで未知型を壊さない。
- PARAM入力式の実行時評価と式保存の区別。文字値を返す式の正式文法。
- PARAM[n]による未設定配列の変更可否。資料では設定済み項目の変更のみと記載。
- COPY / INCLUDE / OLDの厳密な動作と参照の維持規則。
- 複数型が混在したメンバーリストでのNAREF数値指定の範囲。
- GPART / PRTELEの許される親子構成、選択テーブルTABITE→TABQUE等の詳細。
- COLOUR / REPRESENTATIONのCOMPARE、CONNECTOR、AIDS、HOLES、MASSPROPERTIES、DARCTOLERANCEの詳細。
- OBST・TUFLA・CLFLAの複数条件が成立したときの線種や表示優先。
- PCON未設定時の値、PBORの特殊な語値の有無。説明文だけで全型をwordとして許可しない。

## 4. ユーザー判断がまだない項目

- PTSETとGMSETの正式な命名対応ルール。現状の仮照合を正式規則と記録しない。
- 実機互換表示モードと、編集用に全要素を見せるプレビューのUIの最終形。
- 写真で得た大量の規則をどの順序で実装するか。今回の依頼は記録保存であり、一括実装ではない。

## 5. コードと照合する実装課題

以下は仕様から生じる確認対象で、全件を不具合または未実装と断定した一覧ではありません。コード基準点 `eacf351` とREADMEを参照してから対象を決めます。

- 明示単位・指数・帯分数・物理次元を含む実機マクロ入力／出力。
- NSDS型の追加、正プリミティブが負プリミティブを持つ階層。
- GPARTと選択テーブルの管理。
- 未指定属性のDB既定値と、UIの未入力表示の区別。
- 符号付きSCYL高さを保った配置・実寸評価・ハンドル操作。
- 中立軸NAREFの明示参照、メンバー順変更、未設定時のPKEY優先順位。
- 仮値エンジンと実寸エンジンの分離、単位次元の扱い、保温なし0と未取得コンテキストの区別。
- Attached / Owning / Insulation / Design各familyの値と役割名の出所。
- MODEL SETTINGSとREPRESENTATIONの実機互換処理。矛盾がある項目を独断で決めない。
- E3D実機で実行できるマクロの生成・取込・参照順序・無名要素の保持。

既知のプレビュー範囲と制限はREADMEに記載されています。負形状はワイヤー重ね表示でブーリアン穴あけではなく、SDSHの厳密曲面、LINEのT点曲線、非ゼロPRADのフィレットなど、未対応と案内している形状があります。仕様メモ追加だけでこれらを対応済みに変えないでください。

## 6. 確認結果の追記方法

実機で確認した場合は、E3Dのバージョン、モジュール、最小の自作入力、初期設定、期待値、実測結果を残してください。私的原本や実プロジェクト名は使いません。

結果を上記IDに紐づけ、解消した点とまだ未確認の点を分けてください。ユーザーが操作要件を変更した場合は、実機仕様の解決とは別にユーザー要件を更新してください。

## 7. ツールへの反映状況（2026-10-16）

ユーザーの「反映して」により、提案した修正を実装しました。E3D実機での確認ではありません。

- R01–R05：全形状表示を既定として残し、属性確認のTUBE・CL・OBST・LEVELとOBST優先条件を明示的に選ぶ方式。資料の矛盾自体は未解消。
- R06：負の第2軸とDDANGLE・TWICEの評価を拡張。未対応の方向構文や多軸回転の完全互換性は未確認。
- SCYL/NSCYの負高さ、点の省略方向＋Y・距離座標0、PSKEY候補、整数LEVEL、NAREF順番号・未設定時の参照順位、NSDS型・子の負形状を追加。
- 既知の単位・PARAM単位・確認用設計値について実寸の次元検査を追加。単位不明の古い値や他familyの数値コンテキストは推定しない。
- DDANGLE等の確認用設計値はツール独自に保存。PARAGONセッションのMODEL SETTINGSをそのまま実装したものではない。
- NSDS/SDSHの実寸曲面、負形状のブーリアン、一般のマクロ入出力、GPART・選択テーブル等の全対応は引き続き未完。
