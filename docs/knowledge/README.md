## 読み方

- **資料確認**: 提示された PDMS/PARAGON 資料に記載されていた内容。E3D 4.0 実機での確認を意味しません。
- **会話継承**: 今回の写真列より前の会話で共有・整理された内容。節番号が残っていない項目はその旨を記載しています。
- **ユーザー決定**: このツールに求められた動作。AVEVA 製品自体の規則とは限りません。
- **要確認**: 資料が矛盾する、構文が十分でない、または実機確認が必要な内容。

実装に使う際は、関連する未確認事項も一緒に読み、確定していない部分を推測で補わないでください。新しい指示や実機結果が得られたら、根拠と対象バージョンを追記してください。
