PTSET → GMSET → SCOM → スペック
段階Aの設計モックです。Pythonアプリには未実装です。 架空データで「出力前確認 → 問題の属性を編集 → 再確認」を試せます。実データの保存・E3Dへの出力は行いません。

確認する対象

SPECの全行と参照部品を含めます。

SCOM A・BとDEMO-SPECを確認します。

共有するPTSET・GMSETも参照先として確認します。

試せる操作

  1. Aだけを選ぶと、Bの不足は確認を妨げません。
  2. 初期状態のB・SPEC・全体では、BのPARAM 3不足が出ます。
  3. チェックを全部外すと「対象なし」になります。

入力・参照を確認して、問題の属性へ移動します。
